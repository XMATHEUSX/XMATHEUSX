## Sobre mim

Tenho experiência com desenvolvimento e manutenção de microserviços e sistemas monolíticos, revisão de pull requests e compartilhamento de conhecimento técnico. Gosto de transformar problemas reais em produtos simples de usar, com uma base técnica sólida.
